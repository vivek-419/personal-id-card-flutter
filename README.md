# Flutter Personal Identity Card

A simple Flutter application that displays personal information in the form of a digital identity card.

## 📱 Project Description

This project was created using Flutter as part of a Flutter assignment. The application demonstrates the use of basic Flutter widgets to create a clean and simple personal identity card.

The card displays the person's profile, name, profession, age, ID number, blood group, location, and email address.

## 🛠️ Widgets Used

The following Flutter widgets are used in this project:

- Scaffold
- AppBar
- Container
- Column
- Row
- CircleAvatar
- Text
- Icon
- SizedBox

## ✨ Features

- Digital personal identity card
- Profile avatar using `CircleAvatar`
- Displays name and profession
- Personal statistics displayed using `Row` and `Column`
- Icons for different personal details
- Location information
- Email displayed at the bottom of the card
- Clean layout with proper spacing using `SizedBox`
- Card-style design using `Container`
